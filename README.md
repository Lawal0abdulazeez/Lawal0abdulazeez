**Autonomous Candidate Screening & Evidence Dossier Engine**

### Multimodal Biometric Security System
**Research-Grade ML Pipeline (Face + Iris + Fingerprint)**  
Advanced biometric identification system using feature-level fusion of Face (LBP), Iris (Log-Gabor), and Fingerprint modalities. Core innovation: Enhanced Chaotic Grey Wolf Optimizer (ECGWO) for simultaneous feature selection and SVM hyperparameter tuning. Full pipeline from preprocessing → fusion → optimization → evaluation with FAR/FRR/EER metrics and baseline comparisons.
